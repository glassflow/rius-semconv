## Notes

**[1] `codex.cwd`:** Kept so a reader of older coding-agent traces can tell what the key was.

**[2] `codex.git_branch`:** Kept so a reader of older coding-agent traces can tell what the key was.

**[3] `codex.originator`:** Copied from the session's metadata in Codex's rollout file (the CLI, codex
exec, an IDE). Codex tags its own metrics with the same word.

Namespace exception: Named after the coding agent that produced it, like every key the
coding-agent plugin writes for a fact only that agent has. Shipped before
the plugin was registered here.

**[4] `codex.subagent.id`:** As cc.subagent.id, for Codex, and not gen_ai.agent.id for the same reason.

Namespace exception: Named after the coding agent that produced it, like every key the
coding-agent plugin writes for a fact only that agent has. Shipped before
the plugin was registered here.

**[5] `codex.turn.aborted`:** The reason Codex gives for aborting the turn, or "aborted" when it gives
none. Absent on a turn that finished. A string despite the name, because
it carries the reason.

Namespace exception: Named after the coding agent that produced it, like every key the
coding-agent plugin writes for a fact only that agent has. Shipped before
the plugin was registered here.

**[6] `codex.turn.duration_ms`:** Codex's own measurement, kept beside the span's start and end, which the
plugin derives from rollout timestamps.

Namespace exception: Named after the coding agent that produced it, like every key the
coding-agent plugin writes for a fact only that agent has. Shipped before
the plugin was registered here.

**[7] `codex.turn.id`:** The turn id Codex writes in its rollout file, on the finished turn span,
so a span can be matched to the rollout it came from.

Namespace exception: Named after the coding agent that produced it, like every key the
coding-agent plugin writes for a fact only that agent has. Shipped before
the plugin was registered here.

**[8] `codex.turn.ttft_ms`:** Measured per turn, not per model call, so it is not
gen_ai.response.time_to_first_chunk, which belongs on an inference span
and is in seconds.

Namespace exception: Named after the coding agent that produced it, like every key the
coding-agent plugin writes for a fact only that agent has. Shipped before
the plugin was registered here.

**[9] `codex.version`:** Kept so a reader of older coding-agent traces can tell what the key was.
